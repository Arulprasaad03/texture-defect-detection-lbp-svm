# 🧠 Texture-Based Defect Detection (LBP + SVM)

## 📌 Overview

This project focuses on detecting surface defects using lightweight texture-based methods.  
We use Local Binary Patterns (LBP) and Support Vector Machines (SVM) on the MVTec AD dataset.

## 🎯 Objectives

- Extract multi-scale texture features
- Compare performance across scales
- Build a lightweight anomaly detection pipeline

## 📂 Dataset

- MVTec AD (MVTec Anomaly Detection Dataset)
- Industrial defect detection benchmark with real-world textures and objects

## ⚙️ Methodology

1. Image preprocessing
2. Feature extraction (LBP)
3. Multi-scale analysis
4. Classification using SVM

## 📊 Expected Outcomes

- Accuracy comparison across scales
- Efficient defect detection model

## 🛠 Tech Stack

- Python
- OpenCV
- Scikit-learn
- NumPy
